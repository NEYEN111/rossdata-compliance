# Guion de demostración · Caso 7

Duración: 8–10 minutos. Usar únicamente datos ficticios. Iniciar con `cumplimiento` / `AndeClass2026!` (o con la contraseña que hayas establecido).

## 1. Presenta el problema · 1 minuto

Desde Dashboard: «AndeClass maneja datos académicos y de salud, usa nube en Estados Unidos y proyecta operar en más países. A las 10:15 conoce una exposición de 320 usuarios. Debemos justificar las decisiones, no solo eliminar el archivo».

Señala la cadena tratamiento → jurisdicción → finalidad → base → transferencia → riesgo → control → evidencia. El porcentaje del dashboard mide controles evaluados, no cumplimiento legal.

## 2. Haz participar al público · 2 minutos

Abre Laboratorio del Caso 7. Pregunta: «¿Qué cambia si los datos de bienestar se usan para publicidad?». Selecciona **01 · Salud → publicidad**: salud, nueva finalidad, transferencia y mecanismo por verificar generan revisiones diferentes.

Selecciona **03 · Uso académico**. Marca base y seguridad: sin evidencia y fundamento no mejora el contador. Selecciona la política ficticia validada y explica: «Referencia de ensayo; su suficiencia requiere revisión humana». Evalúa y muestra 2 → 0 revisiones pendientes. Esto cuenta documentación, no certifica cumplimiento. Guarda la comparación y ábrela; también hay un ensayo de ejemplo guardado durante la verificación.

## 3. Explica la matriz · 2 minutos

Abre Matriz, filtra España/UE y salud. Pulsa el estado de Bienestar estudiantil para ver la explicación. Muestra motivos concretos, responsable, transferencia y evidencia pendiente. Desciende a las obligaciones y al formulario de revisión por país.

Explica que la estancia temporal en España exige analizar el alcance del RGPD. Para salud se registra una condición específica; para nueva finalidad se registra compatibilidad o autorización con fundamento. No completes «Cumple» solo para obtener un color verde.

Desde Riesgos, abre Transferencia internacional sin garantía validada: el control está enlazado explícitamente y muestra si falta evidencia. En Evidencias puedes adjuntar un archivo ficticio de `docs/evidencias_demo/`; al subirlo el estado pasa a En revisión. El archivo admite descarga autenticada y muestra su huella.

## 4. Gestiona el incidente · 2 minutos

Abre INC-001. Muestra los 320 titulares, salud, las ocho etapas y las tarjetas Perú / España. Las decisiones separan **autoridad** y **titulares**. El responsable justifica aplicabilidad, consecuencias, decisión y plazo; los pendientes bloquean el avance.

Para ensayar hasta el cierre, crea un incidente nuevo con código único y datos ficticios. Avanza Contener → Evaluar → Registrar. Completa ambas revisiones por país. La decisión global debe coincidir con las decisiones de notificación de los países. Si corresponde notificar, registra evidencia **Notificación**, validada, para cada país y el mismo tratamiento; vincúlala en su revisión. Corregir y Cerrar también exigen respaldo validado. Todo es una simulación: no se envía una comunicación real.

No uses México/Colombia como afectados solo porque exista expansión prevista. INC-001 permanece abierto en la entrega para que puedas exponerlo.

## 5. Demuestra el resultado · 1 minuto

Abre Auditoría: autor, hora, acción y cambios anterior/nuevo. En Reportes muestra las decisiones por país y motivos de matriz; exporta CSV o imprime el reporte actualizado. Descarga el informe académico, que contiene problema, propósito, funciones, matriz normativa, riesgos, preguntas críticas y conclusiones.

Cierra con: «Podemos explicar qué se revisó, qué falta y con qué evidencia. El software apoya la decisión del responsable».

## Preparación

- Ejecutar `iniciar.bat` y abrir http://127.0.0.1:5000 antes de exponer.
- Mantener a mano el PDF académico; personalizar portada/autores en su fuente Markdown si la institución lo requiere.
- Practicar una vez. Los registros son persistentes; reiniciar el servidor no borra la demo.
- Para repetir ensayos usa el laboratorio; para repetir el incidente, crea otro registro. No borres la base que contiene tu trabajo.
- El Auditor puede consultar, evaluar escenarios temporales y exportar; no puede guardar ni modificar registros.
